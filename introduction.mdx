Wachat gives you a straightforward REST API to build WhatsApp messaging directly into your applications. Every request goes to a single base URL, authenticates with a Bearer token, and returns a JSON response — so you can integrate Wachat with any language or framework that can make an HTTP request.

## Base URL

All API requests target the following base URL:

```bash
https://app.wachat.net/api/v1
```

## Authentication

You authenticate every request by passing your API token in the `Authorization` header:

```bash
curl https://app.wachat.net/api/v1/account/limits \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Note>
  Find your API token in the Wachat dashboard under **Settings → API Keys**. Keep it server-side and never expose it in client code or public repositories.
</Note>

## Response Format

Every endpoint returns `application/json`. Successful responses include a `success: true` field alongside the resource payload. Error responses carry a standard HTTP status code and a descriptive message body.

```json
{
  "success": true,
  "account": {
    "teamId": 25,
    "teamName": "Jakarta Team"
  }
}
```

## Common HTTP Status Codes

| Status | Meaning |
|--------|---------|
| `200` | Request succeeded |
| `201` | Resource created |
| `400` | Invalid request payload or missing parameter |
| `401` | Missing or invalid API key |
| `403` | Subscription does not allow this action |
| `404` | Resource not found |
| `409` | Conflict (e.g., instance still connected) |
| `500` | Internal server error |
