---
title: "DELETE /instance/delete — Remove a WhatsApp Instance"
sidebarTitle: "Delete Instance"
description: "Permanently remove a WhatsApp instance from your Wachat account. The instance must be fully logged out before you call this endpoint."
---

Deleting an instance permanently removes it from your Wachat account — along with its configuration, session credentials, and associated data. Because this action is irreversible, the API enforces a hard prerequisite: you must disconnect the instance by calling [DELETE /instance/logout](/api-reference/instance-logout) before deletion. If you skip this step and call delete while the instance is still connected, the API returns `409 Conflict`.

<Warning>
  You must log out the instance before deleting it. Calling this endpoint while the instance is still connected returns `409 Conflict` with `reason: "instance_still_connected"`. See [DELETE /instance/logout](/api-reference/instance-logout) for the logout procedure.
</Warning>

## Endpoint

```
DELETE https://app.wachat.net/api/v1/instance/delete
```

## Authentication

```
Authorization: Bearer YOUR_API_KEY
```

## Query Parameters

<ParamField query="instanceName" type="string" required>
  The `apiInstanceName` returned when you created the instance (e.g. `t1_mq9r2jov_jakarta_store`). Do not use the friendly display name.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` when the delete request completed successfully.
</ResponseField>

<ResponseField name="message" type="string">
  A human-readable confirmation message (e.g. `"Instance deleted successfully."`).
</ResponseField>

<ResponseField name="instance" type="object">
  Summary of the deleted instance.

  <Expandable title="instance fields">
    <ResponseField name="instance.id" type="integer">
      Internal numeric ID of the deleted instance.
    </ResponseField>
    <ResponseField name="instance.instanceName" type="string">
      The `apiInstanceName` that was deleted.
    </ResponseField>
    <ResponseField name="instance.displayName" type="string | null">
      The friendly display name of the deleted instance.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="instanceDeleted" type="boolean">
  `true` when the instance delete request to the Wachat backend succeeded.
</ResponseField>

<ResponseField name="instanceMissing" type="boolean">
  `true` when the instance was already missing from the Wachat backend before the delete was attempted. This can happen if the instance was removed externally.
</ResponseField>

<ResponseField name="connectionState" type="string">
  The last connection state detected before the instance was removed (typically `"close"` for a properly logged-out instance).
</ResponseField>

## Error Codes

| Code | Meaning |
|------|---------|
| `400` | Missing `instanceName` query parameter, or the integration type does not support deletion. |
| `401` | Missing or invalid API key. |
| `403` | Your subscription plan prevented instance deletion. |
| `404` | No instance found for this API key with the given name. |
| `409` | The instance is still connected. Log it out first with [DELETE /instance/logout](/api-reference/instance-logout). |
| `502` | Wachat could not verify the state or delete the instance on the backend. |
| `504` | The request to the Wachat backend timed out. |

## Example

<Steps>

  <Step title="Log out the instance first">

    Ensure the instance is disconnected before attempting deletion.

    ```bash
    curl -X DELETE \
      "https://app.wachat.net/api/v1/instance/logout?instanceName=t1_mq9r2jov_jakarta_store" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

  </Step>

  <Step title="Delete the instance">

    Once logged out, send the delete request.

    <CodeGroup>

    ```bash cURL
    curl -X DELETE \
      "https://app.wachat.net/api/v1/instance/delete?instanceName=t1_mq9r2jov_jakarta_store" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    ```javascript Node.js
    const instanceName = "t1_mq9r2jov_jakarta_store";

    const response = await fetch(
      `https://app.wachat.net/api/v1/instance/delete?instanceName=${instanceName}`,
      {
        method: "DELETE",
        headers: { Authorization: "Bearer YOUR_API_KEY" },
      }
    );

    if (response.status === 409) {
      console.error("Instance is still connected. Log out first.");
    } else if (response.ok) {
      const data = await response.json();
      console.log("Deleted:", data.instanceDeleted);
    }
    ```

    ```python Python
    import requests

    response = requests.delete(
        "https://app.wachat.net/api/v1/instance/delete",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        params={"instanceName": "t1_mq9r2jov_jakarta_store"},
    )

    if response.status_code == 409:
        print("Instance is still connected — log out first.")
    elif response.ok:
        print("Instance deleted:", response.json()["instanceDeleted"])
    else:
        print(f"Error {response.status_code}: {response.text}")
    ```

    </CodeGroup>

  </Step>

  <Step title="Confirm the response">

    A successful delete returns a `200` with `instanceDeleted: true`.

    ```json Example response
    {
      "success": true,
      "message": "Instance deleted successfully.",
      "instance": {
        "id": 26,
        "instanceName": "t1_mq9r2jov_jakarta_store",
        "displayName": "jakarta_store"
      },
      "instanceDeleted": true,
      "instanceMissing": false,
      "connectionState": "close"
    }
    ```

  </Step>

</Steps>

### 409 Conflict Response — Instance Still Connected

If you attempt to delete a connected instance, the API returns:

```json
{
  "success": false,
  "error": "Instance must be logged out before deletion.",
  "reason": "instance_still_connected",
  "connectionState": "open"
}
```

<Note>
  Deletion is permanent and cannot be undone. Any contacts, message history, or webhook configurations associated with this instance will be removed. Make sure you have exported or migrated any data you need before deleting.
</Note>
