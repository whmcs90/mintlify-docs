---
title: "DELETE /instance/logout — Disconnect WhatsApp Session"
sidebarTitle: "Logout"
description: "Gracefully disconnect a WhatsApp instance from its active session. The instance remains in your account and can be reconnected by scanning a new QR code."
---

Logging out severs the live WhatsApp connection for an instance — it clears the session credentials and drops the socket — but it does not remove the instance from your account. After a logout, the instance transitions to a disconnected state and you can reconnect it at any time by scanning a new QR code. You must log out an instance before you can delete it.

## Endpoint

```
DELETE https://app.wachat.net/api/v1/instance/logout
```

## Authentication

```
Authorization: Bearer YOUR_API_KEY
```

## Query Parameters

<ParamField query="instanceName" type="string" required>
  The `apiInstanceName` returned when you created the instance (e.g. `t1_mq9r2jov_jakarta_store`). Do not use the friendly display name.
</ParamField>

## Response

A `200 OK` response indicates the session was successfully terminated and the instance is now offline. There is no JSON body beyond a success acknowledgement.

## Error Codes

| Code | Meaning |
|------|---------|
| `400` | Missing `instanceName` query parameter. |
| `401` | Missing or invalid API key. |
| `404` | No instance found for this API key with the given name. |
| `502` | Wachat could not complete the logout on the backend. |

<Warning>
  Always log out an instance before deleting it. If you call [DELETE /instance/delete](/api-reference/instance-delete) while the instance is still connected, you will receive a `409 Conflict` error. Logout first, then delete.
</Warning>

## Example

<CodeGroup>

```bash cURL
curl -X DELETE \
  "https://app.wachat.net/api/v1/instance/logout?instanceName=t1_mq9r2jov_jakarta_store" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const instanceName = "t1_mq9r2jov_jakarta_store";

const response = await fetch(
  `https://app.wachat.net/api/v1/instance/logout?instanceName=${instanceName}`,
  {
    method: "DELETE",
    headers: { Authorization: "Bearer YOUR_API_KEY" },
  }
);

if (response.ok) {
  console.log("Instance logged out successfully.");
} else {
  console.error(`Logout failed: ${response.status}`);
}
```

```python Python
import requests

response = requests.delete(
    "https://app.wachat.net/api/v1/instance/logout",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"instanceName": "t1_mq9r2jov_jakarta_store"},
)

if response.ok:
    print("Instance logged out successfully.")
else:
    print(f"Error {response.status_code}: {response.text}")
```

</CodeGroup>

## Logout Before Delete — Recommended Sequence

Follow this order when you need to permanently remove an instance:

<Steps>

  <Step title="Verify the current state">
    Call [GET /instance/state](/api-reference/instance-state) and confirm `instance.state` is `"open"` before attempting a logout.
  </Step>

  <Step title="Log out the instance">
    Call `DELETE /instance/logout?instanceName=YOUR_API_INSTANCE_NAME`. Wait for a `200 OK`.
  </Step>

  <Step title="Delete the instance">
    Call [DELETE /instance/delete](/api-reference/instance-delete) only after the logout succeeds. This permanently removes the instance from your account.
  </Step>

</Steps>

<Note>
  After logout, the instance stays in your Wachat account in a disconnected state. Re-scan a QR code at any time to bring it back online without losing any configuration or associated contacts.
</Note>
