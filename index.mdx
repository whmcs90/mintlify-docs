Wachat is a WhatsApp messaging infrastructure platform that lets you integrate WhatsApp into your applications through a single, reliable REST API. Connect WhatsApp instances, send rich interactive messages, verify phone numbers, and subscribe to real-time delivery and conversation events — all without managing phone hardware or WhatsApp clients directly.

## Get started in three steps

<Steps>
  <Step title="Get your API token">
    Sign in to your [Wachat dashboard](https://app.wachat.net) and copy your API token from **Settings → API Keys**.
  </Step>
  <Step title="Create a WhatsApp instance">
    Call `POST /instance/create` to provision a new WhatsApp connection, then scan the QR code to link your phone number.
  </Step>
  <Step title="Send your first message">
    Call `POST /send/text` with your `instanceName` and a recipient number to send a WhatsApp message from your application.
  </Step>
</Steps>

<Warning>Keep your API token server-side. It grants full access to your WhatsApp instances and messaging quota — never expose it in client-side code or public repositories.</Warning>

<Tip>Every endpoint in the API Reference includes a live **Try It** playground so you can test requests and inspect real responses directly from the docs.</Tip>
